# Clave Segura Pro 🔐

Generador de contraseñas personalizable, ideal para proteger tus proyectos web, sistemas escolares, videojuegos, etc. ¡Detectamos y corregimos errores, y además mejoramos la experiencia de usuario!

## 🚀 Descripción
Esta aplicación permite generar contraseñas seguras de manera sencilla y rápida, eligiendo el tamaño y los tipos de caracteres a incluir (mayúsculas, números y símbolos). El proyecto surgió como práctica de depuración y mejora de código real.

## 🛠️ Funcionalidades
- Selección del tamaño de la contraseña (entre 6 y 25 caracteres)
- Opciones para incluir mayúsculas, números y símbolos
- Copiado fácil de la contraseña generada
- Mensajes visuales de confirmación y error
- Interfaz moderna y responsiva

## 🐞 Correcciones y mejoras realizadas
- Corregidos errores de sintaxis en HTML, CSS y JS
- Unificados nombres de archivos enlazados
- Mejorado el diseño visual y la experiencia de usuario
- Validación: no permite generar contraseñas vacías
- Mensajes visuales en vez de alertas
- Uso de la API moderna para copiar al portapapeles
- Contraseña generada automáticamente al cargar la página
- Código comentado y documentado

## 📋 Instrucciones de uso
1. Clona o descarga este repositorio.
2. Abre `index.html` en tu navegador.
3. Ajusta las opciones a tu gusto y genera tu contraseña segura.
4. Haz clic en "Copiar" para guardarla en tu portapapeles.
